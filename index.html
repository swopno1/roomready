Works with zero internet

RoomReady is built for the airplane-mode test:

  • No network calls. Every asset is local. Open DevTools → Network and reload: zero remote requests.
  • Service worker. On first load the worker caches the whole app, so it opens even with wifi and data off.
  • On-device storage. Rooms, checklists and tickets live in your browser's local storage. Nothing leaves the device.
  • Live indicator. The badge in the header follows the real network state — turn on airplane mode and watch it switch to Offline while the app keeps working.

Try it: turn on airplane mode, reload the page, update a room, add a ticket. Everything still works.
